# 商户政策与规则

## 一、退款政策

### 1.1 退款申请条件
- 订单支付后7天内可申请退款
- 服务未开始使用的订单全额退款
- 已部分使用的订单按实际使用天数扣除后退还
- 退款金额原路返回支付账户

### 1.2 退款审核流程
- 普通退款: 系统自动审核，1-3个工作日到账
- 大额退款（>5000元）: 需人工审核，3-5个工作日到账
- 争议退款: 商户与平台协商处理，最长15个工作日
- 退款渠道: 微信支付/支付宝/银行转账，按原支付方式返回

### 1.3 退款失败常见场景
- 支付通道返回超时（如微信支付回调超时）
- 退款金额超过商户账户余额
- 订单已进入结算周期无法退款
- 原支付账户已注销/冻结

## 二、结算规则

### 2.1 商户分润模式
- 直营模式: 平台统一运营，商户分润60%
- 联营模式: 商户自主运营，商户分润50%
- KA模式: 大客户特殊协议，分润比例按合同约定（40%-70%）
- 分润计算公式: 有效订单总额 × 分润比例 = 结算金额

### 2.2 结算周期
- 标准周期: 每月1日出上月账单，5日前捏结，10日前打款
- 周结商户: 每周一出上周账单，周三前打款（KA商户可选）
- 结算单状态: 待生成 → 已生成 → 已捏结 → 已推送 → 已打款 → 已完成

### 2.3 结算异常处理
- 对账差异: 商户可在出账后3个工作日内申述对账
- 结算补差: 确认差异后5个工作日内补发
- 标签变更: 商户类型标签变更需审批，标签影响着分润比例

## 三、资产管理规则

### 3.1 免时长额度
- 来源: 商户采购套餐 / 平台赠送 / 活动奖励
- 有效期: 购买后12个月内有效，过期自动回收
- 分配范围: 仅可分配给本商户绑定的员工
- 保护期: 员工解绑后30天内不可被其他商户分配

### 3.2 额度回收场景
- 过期回收: 额度到期未使用，系统自动回收
- 违规回收: 商户违规操作，平台强制回收
- 主动回收: 商户可手动回收已分配但未使用的额度
- 回收后额度: 回到商户可用余额池

### 3.3 套餐配置
- 基础套餐: 30天免时长 / 60天免时长 / 90天免时长
- 企业套餐: 180天 / 365天（KA商户专属）
- 按次计费: 单次使用0.5元/次（不使用免时长的商户）
- 按天计费: 日均1.5元/天（灵活计费模式）
- 按电量计费: 按实际充电量计费（充电站场景）

## 四、合同管理

### 4.1 合同类型
- 入驻合同: 商户首次入驻时签署，约定基本合作框架
- 续签合同: 合同到期前30天发起的续签流程
- 补充协议: 特殊条款变更（如分润比例调整、经营范围变更）
- 合同状态: 草稿 → 待签署 → 已签署 → 生效中 → 即将到期 → 已到期

### 4.2 合同变更流程
- 标准变更: 双方协商确认 → 法务审批 → 系统更新
- 紧急变更: 业务VP审批 → 法务备案 → 系统更新（24小时内生效）
- 合同签署后，系统自动同步分润比例和结算规则到业务系统

## 五、风控与合规

### 5.1 商户风控规则
- 异常交易监控: 单日交易额波动超过200%触发预警
- 退款率监控: 月度退款率超过15%触发审核
- 投诉率监控: 月度投诉工单超过5单触发冻结
- 风控限制: 限制交易 / 冻结账户 / 限制提现 / 清退

### 5.2 商户清退流程
- 触发条件: 严重违规 / 连续3月亏损 / 合同到期不续
- 清退步骤: 通知商户 → 冻结交易 → 结算清算 → 数据归档
- 清退状态: 预警期(7天) → 清退中(30天) → 已清退
