# 商户后台操作指引

## 一、工单提交流程

### 1.1 如何提交工单
1. 登录商户后台 → 点击"工单管理" → "新建工单"
2. 选择问题类型: 订单异常 / 资产分配 / 结算问题 / 账户管理 / 其他
3. 填写工单描述: 务必包含订单号/用户手机号/具体异常表现
4. 上传截图附件: 异常页面截图、支付凭证等
5. 提交后可在"我的工单"查看处理进度

### 1.2 工单状态说明
- 待处理: 工单已提交，等待客服分配
- 处理中: 客服/研发正在排查
- 待补充: 信息不足，需要商户补充材料
- 已解决: 问题已修复，等待商户确认
- 已关闭: 商户确认解决或超时自动关闭

### 1.3 常见提交流程问题
- 工单未得到及时回复: 检查是否在"待补充"状态，需补充信息
- 工单被自动关闭: 超过72小时未回复确认，系统自动关闭
- 工单重复提交: 同一问题不要重复提交，在原工单下追加评论

## 二、资产管理操作

### 2.1 查看资产余额
- 路径: "资产管理" → "额度总览"
- 展示: 总额度 / 已分配额度 / 剩余可用额度 / 即将过期额度
- 额度预警: 剩余<20%时系统自动提醒

### 2.2 分配免时长给员工
- 路径: "资产管理" → "额度分配" → "新增分配"
- 步骤: ① 输入员工手机号 ② 选择分配天数和类型 ③ 确认分配
- 注意事项: 
  - 员工必须已绑定本商户
  - 分配数量不能超过剩余可用额度
  - 保护期内的员工不可被分配

### 2.3 回收已分配额度
- 路径: "资产管理" → "额度分配" → 找到目标记录 → "回收"
- 回收条件: 额度尚未被使用
- 回收后: 额度回到可用余额池

### 2.4 常见资产问题
- 分配时提示"余额不足": 检查剩余可用额度 → 回收未用额度 或 采购新套餐
- 分配时提示"用户不可分配": 用户在保护期内 → 等待保护期结束
- 额度莫名减少: 查看回收记录 → 可能是系统自动回收过期额度

## 三、订单查询操作

### 3.1 查询订单
- 路径: "订单管理" → "订单查询"
- 检索方式: 按订单号 / 用户手机号 / 时间范围 / 订单状态
- 订单状态: 待支付 / 已支付 / 服务中 / 已完成 / 待退款 / 已退款 / 已取消

### 3.2 退款操作
- 路径: "订单管理" → 找到目标订单 → "申请退款"
- 退款审核: 系统自动审核（1-3个工作日）
- 退款进度: 审批中 → 退款中 → 已退款

### 3.3 常见订单问题
- 订单支付了但服务未生效: 可能是支付回调延迟 → 等待5分钟后刷新
- 订单状态异常: 尝试清除缓存或联系客服
- 订单历史查不到: 检查筛选条件和时间范围

## 四、结算查询操作

### 4.1 查看账单
- 路径: "财务管理" → "账单查询"
- 账单周期: 选择账期（如2026年8月）
- 账单明细: 总金额 / 费用分项 / 计算依据

### 4.2 结算进度查询
- 路径: "财务管理" → "结算管理"
- 结算状态: 待生成 → 已生成 → 已捏结 → 已推送 → 已打款 → 已完成
- 打款时间: 每月10日前（标准周期）

### 4.3 对账申述
- 路径: "财务管理" → "账单查询" → 目标账单 → "申述对账"
- 申述时限: 出账后3个工作日内
- 处理时效: 确认差异后5个工作日补发

### 4.4 常见结算问题
- 账单多算了/少算了: 申述对账 → 提供对比数据 → 等待核实
- 结算迟迟不到账: 检查结算状态 → 确认打款银行信息 → 联系客服
- 分润比例不对: 检查合同分润比例 → 确认商户类型标签是否正确 → 联系客服修正

## 五、账户管理

### 5.1 员工管理
- 新增员工: "账户管理" → "员工管理" → "添加员工"
- 权限配置: 管理员 / 操作员 / 只读
- 员工离职: 解绑员工 → 释放已分配额度（保护期内不可被其他商户分配）

### 5.2 商户信息维护
- 基本信息: 商户名称、联系人、联系电话、地址
- 合同信息: 查看合同类型、分润比例、有效期
- 银行信息: 结算收款账户维护

### 5.3 常见账户问题
- 员工登录提示无权限: 检查角色分配 → 联系管理员分配权限
- 合同到期了: 系统自动提醒 → 联系商务续签
- 商户被冻结了: 查看冻结原因 → 联系风控/客服处理
